## 3. 未修复项（记录，不阻断 0.7.0）

均为 P2 且需实机交互验证或属架构清理，按「先发布、后续 0.7.x 处理」处置；已在 CHANGELOG `Known limitations`/本报告披露。

| 域 | 项 | 理由 |
|---|---|---|
| 浮窗 | `dispose()` 不自行还原注入（由 `index.js` 兜底）；边缘把手「点一下」不抬升窗口；零位移 `pointermove` 仍提交 resize；`lastFocusedAt` 不随实际聚焦更新（满槽淘汰依据失真）；`openTabs` 不可用时静默删除 docked 记录；`markAllPeeked` 把 docked 也标为 peeked；`floatTagSetTop(null)` 语义不符；grip 的 a11y 角色 | 风险集中在服务漂移/混合态边界，改动面大于收益；需真实浮窗交互回归 |
| 核心 | 宿主矩形测量失败无重试；`suppressPrevFocus` 失败分支不复位；`unmountStage` 不清 `focusPreviewSignal`；若干定时器/rAF 未纳入卸载清理；条件 Hook；冗余 drop handler；`onStageReady` 提前 return；`cycleCompanionWrap` 无 disposer | 低频或仅诊断/测试路径命中 |
| 基建 | `formatRelative` 用 `Intl` 默认 locale（与插件 i18n 语言可能不一致）；`content.js`/`styles.js` 旁路了 adapter 单一源约定；宿主半零测试 | i18n 需实机确认；净化重构留待 0.7.x |
| 产物 | `window.__ONESTEP__` 全局无条件暴露（含只读快照与会改变舞台状态的 `actions`），探针开关只控制面板；`dsh.sessions.current` 只读回退未列入 README §8 的「非公开扩展」清单 | 与 DSH 页面同源，未扩大信任边界，但建议在 §8 补一句披露 |
| 打包 | `CHANGELOG.md` 未入包（保持 6 文件白名单，决定不加）；缺 `repository`/`homepage`/`bugs`/`keywords`/`author` | 依赖 GitHub 仓库地址定稿（用户决策） |
