# 2026-11-20 项目审查与优化

本轮基于工作区现有改动审查状态管理、候场快照、浮窗生命周期、快速新建和构建验证流程，保留原有功能改动。修复了 8 类问题，新增 15 项回归测试，重新生成客户端产物。下列结论来自本轮源码审查与本地测试，不替代 DSH 实机验证。

## 2. 工程改进

- `npm test` 自动发现 `tests/*.test.mjs`，避免新增测试被手写文件列表遗漏。
- `npm run check` 串联全部单测、构建一致性、i18n、版本范围和文档检查。
- 新增 [GitHub Actions CI](../../.github/workflows/ci.yml)，在 Node 22 / 24 上运行离线门禁；工作流尚未在 GitHub 执行。
- 安全说明补全只读的官方浮窗存储键，开发文档同步构建检查语义。
